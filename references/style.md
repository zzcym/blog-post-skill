# 写作与改写规则

目标读者是"懂一点、但没系统学过"的人。写作的默认姿态是：**我也刚想明白，顺手记下来**，不是"下面我来教你们"。

## 一、文章的形状

一份笔记通常只有一个论点，把它撑成 800–1500 字的结构大致是：

1. **导语**（`<p class="lead">`，1–2 句）：直接说这篇要解决什么困惑，不要"随着深度学习的飞速发展"。
2. **问题**：笔记里那个原始问题，说清楚它为什么是个问题。
3. **直觉**：先给一个不需要公式的解释（一句话能说清最好）。
4. **形式化**：公式、定义、条件。这里是笔记里"放公式"的位置。
5. **细节**：两三个容易被忽略的点（为什么这样、边界情况、代价）。
6. **收束**：一段话，或者 `<hr>` 之后一句后记。

不是每篇都要全，但**顺序别乱**：先问题，后形式；先直觉，后推导。

## 二、语气

- 第一人称，说人话。"我们"和"你"少用，能省就省。
- 具体名词优先。"一个 K 维的实数向量"比"高维特征"好。
- 少形容词。删掉"非常""极其""十分重要"，意思基本不变。
- 不用 emoji，不用感叹号连用，不用"众所周知""毋庸置疑""总而言之"。
- 可以有一点点个人判断（"我个人更愿意把它理解成……"），但不要抒情。
- 破折号——可以用来补一句解释，全文别超过三处。

## 三、纠错：改什么、怎么改

拿到笔记先通读一遍，逐句检查这五类问题。**发现问题就改，但改完要让用户知道改了哪里**。

1. **术语用错或太松**
   例："softmax 是用来解决多分类问题的"
   → 改成："softmax 做的是把一组实数变成一个概率分布；多分类模型的最后一步用它。"
   判据：这个说法会不会让初学者以为 softmax 自己就能分类？

2. **逻辑跳跃**
   笔记里"因为 A，所以 B"，中间其实缺了 C。
   例："为了让概率之和为 1，所以用 softmax" → 中间缺"先要保证每一项是正的，才能用归一化"。
   → 补一句"为什么"。

3. **符号不统一**
   $K$ 和 $C$、$z$ 和 $s$、$x$ 和 $\mathbf{x}$ 混用；下标 $i$ 和 $k$ 混用。
   → 全文统一，并在第一次出现时点明含义。

4. **事实性错误或不精确**
   数学对象写错（把 $\sum p_k$ 写成 $\sum p_i$）、维数对不上、把"概率"和"似然"混用。
   → 改；如果拿不准，写成 `<!-- 待确认：… -->` 并在交付说明里列出来，**不要猜**。

5. **口语残留**
   "然后呢""就是说""这个东西""搞一下"→ 换成具体的说法。但也不必全部消灭，留一两处反而像人写的。

## 四、补充的分寸

**该补的**（笔记没写，但读者一定会卡住）：

- 一个具体的数字例子（"三个类别的 logits 是 2.0 / 1.0 / 0.1，softmax 之后是 0.66 / 0.24 / 0.10"）；
- 为什么是这个形式（exp 保证正数 + 放大差距）；
- 一个代价或坑（数值溢出、$e^{1000}$ 会炸）；
- 一个相邻概念的关系（二分类是 $K=2$ 的特例，可用 sigmoid）。

**不该补的**：

- 为了凑字数展开的背景历史；
- 笔记里没有、你也无法确认的具体数字、论文名、人名；
- 大段教科书式的推导（读者要的是"啊原来如此"，不是证明）。

补的内容要能被一句话概括进交付说明：**"我补了什么，为什么补"**。

## 五、排版细节

- 中文和英文/数字之间加一个半角空格：`用了 softmax 之后`、`K 个类别`（CSS 不会自动加）。
- 中文标点用全角，英文和公式里用半角。
- 数字与单位之间空格：`0.5 秒`。
- 公式里的变量用 `$…$`，不要写成斜体文字。
- 一段 2–5 行。超过 6 行就拆。
- 列表只在真的是并列关系时用；段落能说清就别列表。
- 每节开头别用"首先""其次""最后"套话。

## 六、标题与摘要

**文章标题**（`<h1>` 和 `post:title`）：两段式最好懂——`主标题：一句补充`，或一句完整的话。
- 好：「softmax 到底在做什么：从一堆实数到一个概率分布」
- 差：「关于 softmax 的探讨」「深度学习笔记（三）」
- 不超过 30 个汉字，不用书名号，不用感叹号。

**摘要**（`post:excerpt`，列表页和 RSS 会显示）：一句话，40–70 个汉字，说清"这篇讲了什么"，不是标题的重复。
- 好：「线性层输出的是任意实数，要变成概率，还差一步归一化。」

**标签**（`post:tags`）：1–2 个，**优先复用已有标签**：
`站点`、`指南`、`前端`、`特效`、`项目`、`地图`、`设计`、`界面`、`机器学习`、`数学`、`思考`。
新标签要能覆盖以后的三篇以上，否则不加。

**slug**（文件名）：小写英文，单词之间用 `-`，3 个词以内。
`softmax.html`、`why-softmax.html` 都可以，不要用 `post-20261119.html`。
